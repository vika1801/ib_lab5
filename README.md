# CryptoLab — лаборатория криптографических преобразований и цифрового доверия

Учебный проект лабораторной работы №5. Все данные вымышленные. Классические шифры и LSB — демонстрационные модели, не предназначенные для реальной защиты.

## Запуск (Windows / VS Code)
1. Установите Python 3.10+.
2. Откройте папку проекта в VS Code.
3. В терминале из корня проекта выполните:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python программы/главный_симулятор.py
   ```
   Если PowerShell запрещает активацию, можно не активировать окружение: `.venv\Scripts\python.exe -m pip install -r requirements.txt`, затем запуск `.venv\Scripts\python.exe программы/главный_симулятор.py`.
4. В меню выберите команду: `все`, `классика`, `анализ`, `стего`, `хеш`, `подпись`, `tls`, `инциденты`, `тесты`, `выход`.
5. Для тестов из корня проекта: `python -m unittest discover -s tests -v`.

## Структура
- `данные/` — учебные сообщения, алфавиты/параметры, сценарии и документы.
- `программы/` — реализации алгоритмов, демонстрации, симулятор и тесты.
- `документы/` — описание алгоритмов, протокол экспериментов, анализ инцидентов.
- `отчёты/` — текстовые отчёты, формируемые симулятором.

## Безопасность
- AES-GCM и RSA-PSS реализованы библиотекой `cryptography`.
- При каждом AES-GCM шифровании генерируется случайный nonce; nonce не повторяется в рамках одного вызова с тем же ключом.
- Закрытый ключ создаётся в памяти и не записывается в архив/отчёт.
- Не используйте проект для настоящих документов, паролей или персональных данных.
